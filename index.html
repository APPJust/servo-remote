    連線到開發板

    選擇手機要透過哪一條路，把角度送到伺服馬達。

    和 Webduino Blockly 相同的連線方式：Webduino Smart 連上 Wi-Fi 後，網頁用 Device ID 透過 Webduino 的 MQTT Broker 傳送指令。

    手機網頁→wss://ws.webduino.io→Webduino Smart→SG90

    網頁直接把角度 publish 到 MQTT Broker，開發板 subscribe 同一個 Topic。開發板需要燒錄附的 firmware/ServoMQTT 範例程式。

    手機網頁→ publish →Broker→ subscribe →ESP 開發板→SG90
    Broker（WebSocket 網址）
    Topic（要和開發板程式一致）
    方向Topic內容
    手機 → 板子角度 0–180（純文字）
    板子 → 手機實際角度回報
    板子 → 手機1 在線／0 離線（保留訊息＋遺囑）
    進階：帳號密碼、QoS、保留訊息
    QoS
